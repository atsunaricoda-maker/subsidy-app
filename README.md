# 助成金申請管理システム (Subsidy Manager)

## プロジェクト概要

助成金申請業務のDX化を実現するWebアプリケーションです。顧客とのやり取りを一元管理し、書類提出をオンライン化することで、業務効率を大幅に向上させます。

## 🎯 主な機能

### 管理者側機能
- **管理者認証**: ログイン・ログアウト機能（ユーザー名・パスワード）
- **顧客管理**: 全顧客の一覧表示と詳細情報管理
  - 新規顧客登録（助成金種別の選択を含む）
  - 顧客情報編集（ステータス、担当者、助成金種別、メモなど）
  - 顧客ポータルリンク発行
  - **ポータルURLコピー**: ワンクリックでURLをクリップボードにコピー（顧客一覧・詳細の両方で利用可能）
- **助成金種別管理**: 
  - 専用管理画面（`/subsidy-types`）
  - 5種類の助成金プリセット（IT導入補助金、ものづくり補助金、キャリアアップ助成金、雇用調整助成金、小規模事業者持続化補助金）
  - 新しい助成金種別の作成（名前、カテゴリ、説明、必要書類を一括設定）
  - 各助成金の必要書類追加・削除
  - フレキシブルな書類リスト管理
  - 新しい助成金制度にも即座に対応可能
- **進捗管理**: 5段階のステータス管理（見込み → 相談中 → 書類準備中 → 申請中 → 完了）
- **ダッシュボード**: ステータス別の集計表示（リアルタイム更新）
- **統計・レポート**: 
  - 総顧客数
  - 今月の新規顧客数
  - 今月の完了件数
- **書類管理**: 
  - 顧客がアップロードした書類の確認
  - 書類のダウンロード（R2から直接取得）
  - 書類の承認・差し戻し機能
- **やり取り記録**: チャット形式でのコミュニケーション履歴
- **フィルター・検索**: ステータスや顧客名での絞り込み

### 顧客側機能（顧客ポータル）
- **進捗確認**: 現在の申請状況をリアルタイムで確認
- **書類アップロード**: 
  - ドラッグ&ドロップ対応
  - ファイル選択からのアップロード
  - R2ストレージに直接保存
  - 複数ファイル同時アップロード
- **書類ダウンロード**: アップロード済み書類のダウンロード
- **書類ステータス確認**: 承認済み・差し戻し・確認中の表示
- **必要書類チェックリスト**: 
  - 選択した助成金種別に応じた書類リストを自動表示
  - IT導入補助金なら「ITツール見積書」「IT導入計画書」など
  - ものづくり補助金なら「事業計画書」「設備投資計画書」など
  - 各助成金に特化した書類のみ表示
- **やり取り**: 担当者とチャット形式でコミュニケーション
- **専用URL**: 個別のアクセストークンで簡単ログイン（パスワード不要）

## 📊 データ構造

### データベーステーブル

#### clients（顧客テーブル）
- 顧客の基本情報（名前、会社名、連絡先）
- ステータス管理（inquiry, consulting, preparing, applying, completed）
- アクセストークン（顧客ポータル用）
- 担当スタッフ、メモ

#### documents（書類テーブル）
- 顧客ID（外部キー）
- 書類種別、ファイル名、パス
- アップロード者（client/staff）
- ステータス（pending, approved, rejected）

#### communications（やり取り記録テーブル）
- 顧客ID（外部キー）
- メッセージ内容
- 送信者情報（client/staff）
- 送信日時

#### subsidy_types（助成金種別テーブル）
- 助成金名、説明、カテゴリ（IT系、雇用系など）
- 作成日時

#### subsidy_type_documents（助成金種別ごとの必要書類テーブル）
- 助成金種別ID、書類種別、説明
- 必須/任意フラグ、表示順序

#### document_checklist（必要書類テンプレート - 互換性のため残存）
- 書類種別（登記簿謄本、決算書など）
- 説明文、表示順序

#### admin_users（管理者ユーザーテーブル）
- ユーザー名、パスワードハッシュ
- 管理者名
- 作成日時

### ストレージサービス
- **Cloudflare D1**: SQLiteベースの分散データベース（顧客情報、メタデータ）
- **Cloudflare R2**: S3互換オブジェクトストレージ（書類ファイルの実体保管）

## 📝 使い方

### 管理者の操作手順

1. **ログイン**
   - `/login` からログイン画面にアクセス
   - ユーザー名とパスワードを入力してログイン
   - デフォルト: `admin` / `admin123`

2. **新規顧客登録**
   - トップページの「新規顧客登録」ボタンをクリック
   - 顧客情報を入力して登録
   - 自動生成されたアクセストークンで顧客ポータルURLを発行

3. **進捗管理**
   - ダッシュボードで全体の進捗を確認
   - 顧客をクリックして詳細画面へ
   - 「編集」ボタンから顧客情報とステータスを更新

4. **書類確認**
   - 顧客詳細画面で提出書類を確認・ダウンロード
   - 「承認」または「差戻し」ボタンでステータス更新

5. **やり取り**
   - 顧客詳細画面でチャット形式でコミュニケーション
   - 全履歴が自動保存される

### 顧客の操作手順

1. **ポータルアクセス**
   - 管理者から送られた専用URLにアクセス

2. **進捗確認**
   - 現在の申請状況を確認

3. **書類アップロード**
   - 必要書類チェックリストを確認
   - 書類の種類を選択
   - ファイルをドラッグ&ドロップまたは選択してアップロード

4. **やり取り**
   - 担当者にメッセージを送信
   - 返信を確認

## 🎨 画面構成

### 管理者画面
- `/login` - ログインページ
- `/` - トップページ（顧客一覧・ダッシュボード）※要認証
- `/subsidy-types` - 助成金種別管理 ※要認証
- `/client/:id` - 顧客詳細ページ ※要認証

### 顧客ポータル
- `/portal/:token` - 顧客専用ポータル（認証不要）

### API エンドポイント

#### 認証API
- `POST /api/auth/login` - ログイン
- `POST /api/auth/logout` - ログアウト

#### 顧客管理API
- `GET /api/clients` - 顧客一覧取得
- `POST /api/clients` - 顧客新規登録
- `GET /api/clients/:id` - 顧客詳細取得
- `PUT /api/clients/:id` - 顧客情報更新

#### 書類管理API
- `GET /api/clients/:id/documents` - 書類一覧取得
- `POST /api/clients/:id/documents/upload` - 書類アップロード（FormData）
- `GET /api/documents/:id/download` - 書類ダウンロード
- `PUT /api/documents/:id/status` - 書類ステータス更新

#### コミュニケーションAPI
- `GET /api/clients/:id/communications` - やり取り記録取得
- `POST /api/clients/:id/communications` - メッセージ送信

#### 助成金種別API
- `GET /api/subsidy-types` - 助成金種別一覧取得
- `GET /api/subsidy-types/:id/documents` - 助成金種別の必要書類取得
- `POST /api/subsidy-types` - 助成金種別新規作成
- `POST /api/subsidy-types/:id/documents` - 必要書類追加
- `DELETE /api/subsidy-types/:subsidyId/documents/:docId` - 必要書類削除

#### その他API
- `GET /api/document-checklist` - 必要書類一覧取得（旧形式）
- `GET /api/clients/:id/document-checklist` - 顧客の助成金種別に基づくチェックリスト
- `GET /api/stats` - 統計情報取得

## 💡 使い方のヒント

### 新しい助成金制度が始まった時
1. トップページの「助成金種別管理」ボタンをクリック
2. 「新しい助成金種別を追加」ボタンをクリック
3. 助成金名、カテゴリ、説明を入力
4. 必要書類を追加（「書類を追加」ボタンで複数追加可能）
5. 作成ボタンで完了

### 既存の助成金の書類を追加したい時
1. 助成金種別管理画面を開く
2. 該当の助成金の「詳細・編集」ボタンをクリック
3. 「書類を追加」リンクをクリック
4. 書類名と説明を入力

### 顧客を新規登録する時
1. トップページの「新規顧客登録」ボタンをクリック
2. 「申請する助成金」で適切な助成金を選択
3. 顧客情報を入力して登録
4. 顧客ポータルでは、選択した助成金の書類リストが自動表示されます

### 顧客にポータルURLを送る時
1. **方法1（顧客一覧から）**: 
   - 顧客一覧で対象顧客の「URLコピー」ボタンをクリック
   - トースト通知が表示され、URLがクリップボードにコピーされる
   - LINEやメールに貼り付けて送信
2. **方法2（顧客詳細から）**:
   - 顧客詳細ページの「ポータルURL」セクションにある「コピー」ボタンをクリック
   - URLがクリップボードにコピーされる
   - または「ポータルを開く」リンクで別タブでプレビュー可能
