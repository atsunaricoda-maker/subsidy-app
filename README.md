# 申請らくらく君 (Shinsei-Raku)

## プロジェクト概要

助成金・補助金申請業務のDX化を実現するSaaSプラットフォームです。マルチテナント対応で、複数の士業事務所・コンサルティング会社が独立して利用できます。顧客とのやり取りを一元管理し、書類提出をオンライン化することで、業務効率を大幅に向上させます。

## 🌐 公開URL

- **本番環境**: https://shinsei-raku.com
- **GitHub**: https://github.com/atsunaricoda-maker/subsidy-app

## 🎯 主な機能

### マルチテナント・SaaS機能
- **組織管理**: 各組織が独立したサブドメインで運営（例: `org-name.shinsei-raku.com`）
- **サブスクリプション管理**: Stripe連携による月額課金
  - Basic（月1枠）/ Standard（月3枠）/ Premium（月10枠）/ Business（月30枠）/ Enterprise（月100枠）
  - 追加枠の個別購入（無期限）
- **組織設定**: ロゴ、カラーテーマ、行政書士資格の有無など
- **マスター管理画面**: 全組織の統括管理（`/master`）

### 管理者側機能
- **管理者認証**: ログイン・ログアウト機能（パスワードハッシュ化対応）
- **顧客管理**: 全顧客の一覧表示と詳細情報管理
  - 新規顧客登録（助成金種別の選択を含む）
  - 顧客情報編集（ステータス、担当者、助成金種別、メモなど）
  - 顧客ポータルリンク発行
  - ポータルURLコピー（ワンクリック）
- **案件管理**: 
  - 顧客ごとに複数案件を管理
  - 案件別の進捗追跡
  - 案件アーカイブ・結果記録
- **助成金種別管理**: 
  - 助成金データベース連携
  - 必要書類の自動設定
  - カスタム助成金種別の作成
- **パイプライン管理**:
  - カスタマイズ可能なワークフロー
  - タスク管理・進捗追跡
  - テンプレートからのタスク自動生成
- **従業員管理**: 
  - 従業員アカウントの追加・編集・削除
  - 権限管理
- **請求書管理**:
  - 着手金・成功報酬の請求書発行
  - Stripe決済連携
  - 銀行振込対応
  - 入金確認・消込
- **書類管理**: 
  - 顧客アップロード書類の確認
  - 書類の承認・差し戻し
  - 一括ダウンロード（ZIP）
  - AI書類分析機能
- **書類作成支援**:
  - AIによる事業計画書自動生成
  - ヒアリング回答からの書類作成
  - 書類テンプレート管理
- **エクスポート機能**:
  - 顧客一覧CSV
  - 案件一覧CSV
  - 請求書一覧CSV
- **メール送信機能**: Resend API連携
- **お知らせ機能**: 組織内アナウンスメント

### 顧客側機能（顧客ポータル）
- **進捗確認**: 現在の申請状況をリアルタイムで確認
- **共通書類管理**:
  - 登記簿謄本、決算書など全申請共通の書類
  - 複数期分対応（決算書3期分など）
  - 有効期限管理
  - データ入力モーダル（会社情報の自動抽出支援）
- **案件別書類アップロード**: 
  - ドラッグ&ドロップ対応
  - 書類種別ごとの管理
  - 共通書類との自動連携
- **ヒアリング回答**:
  - 共通質問（会社情報）
  - 案件別質問
  - カテゴリ別整理
- **AI書類作成**（自己作成モード）:
  - ヒアリング回答からAIが事業計画書を自動生成
  - 法的注意事項の同意フロー
- **請求書確認・支払い**:
  - オンライン決済（Stripe）
  - 銀行振込報告
- **やり取り**: 担当者とチャット形式でコミュニケーション
- **専用URL**: 個別のアクセストークンで簡単ログイン（パスワード不要）

## 📊 データ構造

### 主要テーブル

| テーブル | 説明 |
|---------|------|
| `organizations` | 組織（テナント）情報 |
| `admin_users` | 管理者ユーザー |
| `clients` | 顧客情報 |
| `cases` | 案件情報 |
| `documents` | 案件別書類 |
| `client_common_documents` | 共通書類 |
| `common_document_types` | 共通書類タイプ定義 |
| `communications` | やり取り記録 |
| `subsidy_types` | 助成金種別 |
| `subsidy_type_documents` | 助成金別必要書類 |
| `pipelines` | パイプライン定義 |
| `pipeline_tasks` | タスク |
| `invoices` | 請求書 |
| `payments` | 支払い記録 |
| `hearing_questions` | ヒアリング質問 |
| `hearing_answers` | ヒアリング回答 |
| `generated_documents` | AI生成書類 |
| `client_registry_data` | 登記簿データ |
| `client_financial_statements` | 財務諸表データ |

### ストレージサービス
- **Cloudflare D1**: SQLiteベースの分散データベース
- **Cloudflare R2**: S3互換オブジェクトストレージ（書類ファイル保管）

## 💻 技術スタック

- **フレームワーク**: Hono（軽量・高速なWebフレームワーク）
- **ランタイム**: Cloudflare Workers
- **データベース**: Cloudflare D1（SQLite）
- **ストレージ**: Cloudflare R2
- **フロントエンド**: TailwindCSS, Vanilla JavaScript, Axios
- **決済**: Stripe
- **メール**: Resend API
- **AI**: OpenAI API（書類生成・分析）
- **デプロイ**: Cloudflare Pages

## 🚀 開発環境セットアップ

### 前提条件
- Node.js 18以上
- npm

### インストール

```bash
# 依存関係のインストール
npm install

# データベースマイグレーション
npm run db:migrate:local

# テストデータ投入
npm run db:seed
```

### 開発サーバー起動

```bash
# ビルド
npm run build

# サーバー起動（PM2）
pm2 start ecosystem.config.cjs

# または直接起動
npm run dev:sandbox
```
