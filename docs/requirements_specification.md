## 1. プロジェクト概要

### 1.1 システム概要
「申請らくらく君」は、助成金・補助金申請業務のDX化を実現するマルチテナント対応SaaSプラットフォームです。士業事務所・コンサルティング会社が独立したサブドメインで運営し、顧客とのやり取りを一元管理、書類提出をオンライン化することで、業務効率を大幅に向上させます。

### 1.2 ビジネス目標
- 助成金・補助金申請業務の効率化（工数50%削減）
- 顧客とのコミュニケーションコスト削減
- 書類管理のペーパーレス化
- 申請進捗の可視化によるサービス品質向上

### 1.3 ターゲットユーザー
| ユーザー種別 | 説明 |
|-------------|------|
| **マスター管理者** | システム全体の管理（プラットフォーム運営者） |
| **組織管理者** | 各組織（士業事務所等）の管理者 |
| **組織スタッフ** | 各組織の従業員（案件担当者） |
| **顧客** | 助成金申請を依頼する企業・個人 |

## 2. システムアーキテクチャ

### 2.1 技術スタック

| 項目 | 技術 |
|------|------|
| **Webフレームワーク** | Hono（軽量・高速） |
| **ランタイム** | Cloudflare Workers |
| **データベース** | Cloudflare D1（SQLite互換） |

| **メール送信** | Resend API |

| **デプロイ** | Cloudflare Pages |

### 2.2 マルチテナント構成

```
shinsei-raku.com              → ランディングページ・マスター管理
├── /master                   → マスター管理画面
├── /signup                   → 新規組織登録
```

## 5. 非機能要件

### 5.1 パフォーマンス
| 項目 | 要件 |
|------|------|
| レスポンス時間 | 95%のリクエストが1秒以内 |
| 同時接続数 | 1,000同時接続に対応 |
| ファイルアップロード | 最大50MB/ファイル |

### 5.2 可用性
| 項目 | 要件 |
|------|------|
| 稼働率 | 99.9%以上（月間ダウンタイム43分以内） |
| バックアップ | 日次自動バックアップ |
| 災害復旧 | 24時間以内の復旧 |

### 5.3 セキュリティ
| 項目 | 要件 |
|------|------|
| 通信暗号化 | HTTPS必須（TLS 1.2以上） |
| パスワード | bcryptハッシュ化 |
| テナント分離 | organization_idによるデータ分離 |
| アクセス制御 | ロールベースアクセス制御（RBAC） |
